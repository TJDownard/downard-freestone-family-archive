# Working on the family archive

- Cite the supporting source for genealogical claims. Keep source references in `research/sources/`.
- Record conflicting evidence and unresolved claims in `research/verification/`. Identify uncertain conclusions as such in stories and profiles.
- Use relative links between archive pages so the site works from a local copy or a hosted subdirectory.
- Publish details about living people and private records only with the archive owner's approval.
- Keep homepage layout and behavior aligned across Downard, Lambson, Freestone, and Peterson. Start the Downard and Lambson lineages with Robert and the Freestone and Peterson lineages with Judy, then show earlier generations. Check all four views when changing a shared homepage feature.
- Preserve original photos and scans. Use high-quality WebP copies sized for each on-page placement, keep document previews uncropped, and link the full-size image or scan from the Image Library. Include alt text and reserve image space before loading. Lazy-load offscreen previews and check the result on desktop and mobile.
